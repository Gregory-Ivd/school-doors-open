# Двері школи відчинені

Навчальний проєкт реклами соціально-педагогічної роботи з дітьми з інвалідністю в освітньому закладі.

- `index.html` – кликабельний макет сторінки соціального педагога (форма не надсилає дані).
- `poster.pdf`, `poster.png` – макет плаката А3.

Це макет: контакти й назва закладу в квадратних дужках треба замінити, а тексти відповідей має підтвердити школа.
